# Bundled battle maps

Five maps ship here already — click **Bundled maps** in the GM Battle window to load them:

- Grassland Straight Road
- Grassland Curving Road North
- Grassland Crossroads
- Grassland T Junction
- Colosseum (round, 3000px building, entrance on the south side)

Drop more map images in here yourself, then click **Bundled maps** again — maps already loaded are skipped.

- Each image becomes a battlefield scene in a scene folder called "FGA Battle Maps".
- Each scene is staged for you automatically.
- Maps that are already loaded are skipped.
- Types: webp, png, jpg, jpeg, avif, webm, mp4.

## Names and grid size

The file name becomes the scene name. Underscores turn into spaces.

To set the grid size, end the name with the pixels per square:

- `Forest Road_70px.webp` gives the scene "Forest Road" with a 70 pixel grid.
- `Castle Gate.webp` uses the default grid size from the module settings.

Grid size must be 50 or more.
