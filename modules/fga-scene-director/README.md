# fga-scene-director

Foundry VTT module (D&D 5e). Version in module.json.

## Install from GitHub

In Foundry, open Add-on Modules, then Install Module.
Paste this Manifest URL and click Install:

`https://raw.githubusercontent.com/drmogie/fga-foundry-modules/main/modules/fga-scene-director/module.json`
